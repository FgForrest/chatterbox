Klepna je open-source doprovodná aplikace pro AI hlasové rekordéry, založená na projektu [Riffado](https://github.com/riffado/riffado). Spusťte ji na vlastní infrastruktuře pomocí Docker Compose, nebo používejte instanci poskytovanou vaší organizací. Přineste si libovolný API klíč kompatibilní s OpenAI, ponechte si své nahrávky a odejděte, kdykoli budete chtít.

Aktuálně podporuje rodinu Plaud Note — Note, Note Pro a NotePin. Podpora dalších zařízení je na cestě.

- **[Automatizační API a webhooky](/docs/guides/automation-and-webhooks)** —

## Pro ty, kdo provozují vlastní hosting

Provozujete sadu služeb sami s `docker compose up`. Tyto stránky pokrývají instalaci, konfiguraci a pravidelný provoz.

- **[Instalace](/docs/self-hosting/install)** — Docker Compose z příloh
  vydání.
- **[Proměnné prostředí](/docs/self-hosting/environment-variables)** —
  všechny parametry, které Klepna čte při startu.
- **[Pro administrátory](/docs/user-guide/administrators)** — co zapnout
  u jednotlivých funkcí: Organizace, jednotné přihlášení, pošta, Google,
  Claude a další.
- **[S3-kompatibilní úložiště](/docs/self-hosting/storage-s3)** — AWS,
  R2, MinIO, B2 a další.
- **[Nastavení e-mailu (SMTP)](/docs/self-hosting/email-smtp)** — napojení
  odchozí pošty pro službu e-mailových oznámení.
- **[Aktualizace](/docs/self-hosting/upgrading)** — značky obrazů,
  příkaz k aktualizaci a tipy, co zálohovat jako první.
