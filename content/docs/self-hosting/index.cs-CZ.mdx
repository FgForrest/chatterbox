Klepna je software pod licencí AGPL-3.0, který můžete provozovat sami pomocí Docker Compose.
Tato sekce popisuje instalaci, konfiguraci a provoz vlastní instance.

<span id="where-to-start" />

## Kde začít

- **[Instalace](./install)** — jednorázový instalátor přes Docker Compose.
- **[Proměnné prostředí](./environment-variables)** — veškerá nastavení,
  která Klepna načítá při startu, s vyznačením těch, která jsou povinná za běhu.
- **[Organizace](./organization)** — sdílejte nahrávky, přepisy
  a jména mluvčích se všemi uživateli instance.
- **[Jednotné přihlášení](./sso)** — přihlašování přes poskytovatele
  OpenID Connect, například Keycloak.
- **[Externí MCP server](./mcp)** — AI klienti a backendové služby čtou
  Almanach, přepisy, shrnutí a úkoly, s přístupem podle rolí v Keycloaku.
- **[Claude a Claude Code](./claude)** — lidé se na své nahrávky ptají
  Claude (claude.ai, Desktop, Cowork) a Claude Code.
- **[S3-kompatibilní úložiště](./storage-s3)** — přesměrujte zvuk na AWS S3,
  Cloudflare R2, MinIO, Backblaze B2, nebo jakýkoli S3-kompatibilní systém.
- **[Nastavení e‑mailu (SMTP)](./email-smtp)** — propojte SMTP server,
  aby backend pro e‑mailová oznámení mohl doručovat poštu.
- **[Aktualizace](./upgrading)** — tagy obrazů, příkaz pro upgrade
  a co zálohovat před zásadní aktualizací verze.

<span id="not-here" />

## Co zde nenajdete

Chování produktu na úrovni jednotlivých uživatelů — propojení Plaud účtu, volba AI
poskytovatelů, aktivace oznámení, využití veřejného API, export
vašich dat — najdete v sekci [Příručky](../guides) a platí
pro uživatele hostované i s vlastním hostingem.
