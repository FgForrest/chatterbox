Riffado je open-source doprovodná aplikace pro AI hlasové rekordéry. Zaregistrujte se na [riffado.com](https://riffado.com) pro hostovanou instanci, nebo spusťte stejnou kódovou základnu na vlastní infrastruktuře pomocí Docker Compose. Přineste si libovolný API klíč kompatibilní s OpenAI, ponechte si své nahrávky a odejděte, kdykoli budete chtít.

Aktuálně podporuje rodinu Plaud Note — Note, Note Pro a NotePin. Podpora dalších zařízení je na cestě.

## Pro všechny

Tyto návody platí jak pro hostovanou instanci, tak pro vlastní hosting – popisují používání Riffado jako produktu.

  každou nahrávku, přepis a zvukový soubor, abyste mohli kdykoli odejít.

## Pro ty, kdo provozují vlastní hosting

Provozujete stack sami s `docker compose up`. Tyto stránky pokrývají instalaci, konfiguraci a pravidelný provoz.

- **[Instalace](/docs/self-hosting/install)** — instalátor Docker Compose
  na jeden řádek.
- **[Proměnné prostředí](/docs/self-hosting/environment-variables)** —
  všechny parametry, které Riffado čte při startu.
- **[S3-kompatibilní úložiště](/docs/self-hosting/storage-s3)** — AWS,
  R2, MinIO, B2 a další.
- **[Nastavení e-mailu (SMTP)](/docs/self-hosting/email-smtp)** — napojení
  odchozí pošty pro e-mailový backend notifikací.
- **[Aktualizace](/docs/self-hosting/upgrading)** — image tagy,
  příkaz k aktualizaci a tipy, co zálohovat jako první.
