Chatterbox is an open-source companion app for AI voice recorders, based
on [Riffado](https://github.com/riffado/riffado). Run it on your own
infrastructure with Docker Compose, or use an instance your organization provides.
Bring any OpenAI-compatible API key, keep your recordings, leave
whenever you want.

Currently supports the Plaud Note family — Note, Note Pro, and
NotePin. More device support is on the way.

- **[Meeting Recorder](/docs/guides/meeting-recorder)** — record meetings

- **[Connect your Plaud account](/docs/guides/connect-plaud-account)** —

- **[AI providers](/docs/guides/ai-providers)** — wire up OpenAI, Groq,

- **[Backup and restore](/docs/guides/backup-and-restore)** — export

## How it ships

Chatterbox is AGPL-3.0 software. The code supports self-hosted and hosted
deployments; self-host deployments run under your control. Hosted services
and their configuration depend on the instance operator.
